# Student Class

## Attributes

- `studentId`
- `firstName`
- `lastName`
- `dateOfBirth`
- `email`
- `enrolledCourses`
- `grades`

## Behaviour

- `getFullName()` — returns the student's full name.
- `enroll(course)` — adds a course to the student's enrolled courses.
- `drop(course)` — removes a course from the student's enrolled courses.
- `recordGrade(course, grade)` — records a grade for a course.
- `calculateAverageGrade()` — calculates the student's average grade.
